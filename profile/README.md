**Zimam** (زمام, the reins) builds independent, focused apps that keep your things on your own device, in plain files you can open anywhere, with no accounts and no tracking. Control, direction, focused tools, a better you.

## Now building

- **Stabilization first:** bug fixes, cleaner code and tests for Manhal, Thabit and Himma, checked on real phones, before more features.
- **Arabic and right-to-left screens** in every app.
- **Manhal:** text search in a book and translation of selected text. **Thabit:** reminders, repeating tasks and charts. **Falah:** home-screen widget and your own location. **Namaa:** savings goals and bank CSV import. **Himma:** gym plans and meal reminders.
- **Athar** (أثر): a new app, in design.
- **Names:** Rukn is becoming **Manhal** (منهل); Dawem is now **Thabit**; Zimma is now **Namaa**.

## How we build

- **Local first.** No backend unless a product truly needs one; no cloud dependency, no telemetry.
- **Plain files.** Markdown, CSV and JSON you can read, back up and move with any tool.
- **Kotlin and Compose** on Android, Compose Multiplatform on the desktop, Go for the few services that need a server.
- **Every change** goes through a pull request with checks; every release is built, signed and checksummed by a script in the repository.

## Download and verify

Open an app's **Releases** page, take the file for your system, and check it:

```
sha256sum -c <file>.sha256
apksigner verify --print-certs <app>.apk     # compare with the fingerprint in the app's README
```
