## Now building

- **Home pages** in every app: a greeting, rings and charts for today, quick actions and shortcuts, in the Zimam look.
- **First-run tours** and a one-time "What's new" after each update.
- **One folder for everything:** each app keeps its visible data in `Zimam/<App>`, copied across without ever deleting the old folder.
- **Rukn:** PDF editing is out; text search and translation are next. **Dawem:** reminders, recurring tasks and charts. **Falah:** prayer log, compass, timetable, tasbih. **Zimma:** budgets, transfers, recurring entries, who owes whom. **Himma:** gym, steps and meal templates. **Rakeb:** a Go backend. **Rahhala:** maps and QR entry.

## How we build

- **Local first.** No backend unless a product truly needs one; no cloud dependency, no telemetry.
- **Plain files.** Markdown, CSV and JSON you can read, back up and move with any tool.
- **Kotlin and Compose** on Android, Compose Multiplatform on the desktop, Go for the few services that need a server.
- **Every change** goes through a pull request with checks; every release is built, signed and checksummed by a script in the repository.

## Download and verify

Open an app's **Releases** page, take the file for your system, and check it:

```
sha256sum -c <file>.sha256
apksigner verify --print-certs <app>.apk     # compare with the fingerprint in the app's README
```
